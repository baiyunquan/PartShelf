# 机械零件中文别名与自定义规格设计

## 目标

让常用中文名称能搜索到 FreeCAD FastenersWB 对应的机械种类，并允许用户在选定种类后，把来源中没有列出的尺寸直接追加到该种类现有的机械参数表。新增规格应能用于详情浏览、库存引用和 XLSX BOM 尺寸匹配。

## 已确认的约束

- 规格数据写入 PartShelf 使用的 `fasteners.db`，追加到选定标准对应的现有 `fastener_tables` 参数表；不另建独立规格表。
- 上游 `database/FreeCAD_FastenersWB/FsData` 保持只读。原始标准数据与用户追加行通过 `source_file` 区分。
- 已有标准规格和 `fastener:v1` 库存引用保持兼容。
- 用户规格不能因重新导入 FreeCAD 数据而丢失。
- 机械 BOM 仍以器件类型和尺寸匹配；缺少必要尺寸或规格有冲突时不自动绑定。

## 方案

### 中文别名和搜索

新增可维护的中文搜索别名映射，按标准编号或标准族关联中文称呼。首批包含热熔螺母/热熔嵌件到 `IUTHeatInsert`，以及平头螺丝/沉头螺钉到相应沉头标准族。搜索时将输入别名扩展为对应标准编号和英文描述关键词，与现有标准字段和尺寸行键一起查询。详情和列表显示中文别名，英文原始名称和来源描述继续保留。

### 追加自定义规格

- 在机械标准详情页增加“添加规格”入口。表单由该标准现有参数列动态生成：公称规格是单独字段，其余字段对应 `fastener_table_titles`。有独立长度表的标准另外提供长度输入。
- 新行按现有 `fastener_tables` 结构写入 `fastener_standards.param_table_name` 或相应长度表。参数数据仍使用与上游相同列顺序的 JSON 数组，`source_file` 标记为 `user`。不适用于此零件规格的可选尺寸可留空，存成 JSON `null`，不伪造尺寸。
- 允许一个公称规格有多个尺寸组合。用户行使用确定性的 `user:<nominal>:<digest>` 行键；API 同时返回基础公称规格、尺寸和行键。完全相同的规格重复提交时幂等，不产生重复记录。
- 对带独立长度表的自定义尺寸，行键中的公称字段编码为 `nominal@length`，同一个行键同时关联参数行和用户长度行；详情 API 解码后仍分别返回基础公称值和长度。这样 v2 库存引用只需携带精确行键即可还原完整尺寸变体。
- 服务端校验标准存在、表结构可用、零件族的关键匹配尺寸齐全且为有限正数、其他非空数值有效、长度格式有效，并拒绝与同一行键冲突但尺寸不同的写入。参数列和值数量必须一致。
- 规格详情及机械 BOM matcher 识别 `user:` 行键并取回基础公称规格。自定义尺寸变体使用新的版本化机械变体 ID，既能唯一引用同一公称规格下的多个尺寸，也继续解析现有 `v1` ID。

### 重导保留

当前导入器会删除并重建输出数据库。改造后先在临时数据库完整生成上游数据，再从旧库复制 `source_file='user'` 的参数行和长度行；通过表结构、行键和值数量检查后，以原子替换发布新数据库。导入失败时保留原库。这样用户规格仍落在所选种类对应的现有参数表中，同时不会写入 FsData。

### BOM 与库存

- `BomMatcher` 加载上游行和用户行；用户行的基础公称规格从行键解析，尺寸字段按现有标题映射。热熔嵌件要求螺纹公称值、外径和长度可匹配；表中 `D` 列不作为螺纹公称值使用，未提供的其他几何列保持未知，不参与伪造的精确比较。
- 对热熔嵌件解析螺纹公称值、外径和长度；对螺钉解析头型族、公称直径和长度。只有输入中可识别的关键尺寸与候选行一致时才推荐；多个候选保留人工确认。
- XLSX 预览中的自定义候选可通过对应变体 ID 写入库存；提交时重新运行相同尺寸校验。

## 接口

- `POST /api/libraries/fasteners/{standard_code}/specs`：在选定标准的参数表或长度表追加一条自定义尺寸。
- `GET /api/libraries/fasteners/{standard_code}`：继续返回既有响应字段，并在参数行/长度行中增加自定义来源及稳定行键字段。
- 搜索响应保留原字段，增加标准的中文显示名称/别名字段。

请求体使用公称规格、参数字段映射和可选自定义长度；不接受客户端提交表名、SQL 或任意数据库字段名。表名和字段顺序完全由服务端查询标准元数据决定。

## 测试

- 中文别名搜索：`热熔螺母` 命中 `IUTHeatInsert`；`平头螺丝` 命中沉头螺钉族；无关类别不被带入。
- 热熔规格写入：添加 `M3`、外径 `5.5`、长度 `4` 后，详情返回独立用户行，`M3` 默认源规格保持不变，重复提交不重复插入。
- 平头螺丝长度扩展和无效公称值、缺字段、非有限值、非法长度拒绝。
- 写入的行在导入重建后仍存在；模拟导入失败时旧库文件和用户规格保持可读。
- 自定义行可形成唯一库存引用；BOM 的尺寸匹配、预览和提交校验一致；现有 `fastener:v1` 库存引用回归通过。
- 运行机械库和 BOM 测试，以及完整 pytest 套件。

## 不在本轮范围

- 修改或翻译 FreeCAD 上游源文件。
- 改写已有上游标准尺寸。
- 用户规格编辑、删除和批量导入。
- 自动推断缺失尺寸并静默绑定。
