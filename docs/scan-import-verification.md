## 修复与验证

- 二维码在 OCR 之前分流；数量或目录有问题也不回退到 OCR。
- 图片摘要避免空二维码造成错误去重；数据库唯一识别声明合并并发请求。失败结果保存，中断声明超时后成为终态，需要人工核查或新照片。
- JSON Schema、512/1200 token 预算及完成状态检查阻止截断输出自动入库。提取结构压缩为三个查询和封装、主值、品牌，保证提取预算可用；主值按 C/R/L 单位换算核验，其他原文参数保留供人工核查。
- 数量读取完整数字，支持 `1,000` 和 `1 000`；不支持的格式、负数及多个不同数量进入核查。短型号冲突和贴片/直插冲突同样阻止自动入库。
- 元件库来源与 ID 分开传递，Altium ID 不再被当作 C 编号。新动态元件保存为 jlcparts；启动升级规范旧 lcsc_dynamic 来源别名，元件 ID 不变。
- 远程缓存写入前迁移数值索引触发器，保留已有别名，不要求全库重建。
- 原 PP-OCR 默认推理已禁用，已同步本地 ElectronicQwen 镜像；llama.cpp OCR 与适配层保留。
